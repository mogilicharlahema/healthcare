# MediCare+ Complete Hospital UI

Responsive Vite, React and Tailwind CSS v4 application regenerated from the supplied orange mobile UI reference.

## Palette
- Bright orange `#FF681A`
- Deep orange `#F4510B`
- White `#FFFFFF`
- Soft gray `#F8F7F6`
- Charcoal text `#171923`
- Pale orange `#FFF7ED`

## Pages
Welcome, login, dashboard, patients, doctors, appointments, departments, billing, reports, travel, support, settings, profile, patient portal and six dynamic create flows.

## Run
```bash
npm install
npm run dev
```

Open `/welcome` for onboarding, `/login` for sign-in, and `/` for the hospital dashboard. Data changes persist in localStorage.
